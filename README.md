# HTML y CSS - Proyectos prácticos

Este repositorio contiene una colección de proyectos realizados con HTML y CSS como práctica de maquetación web.

Cada proyecto está organizado en su propia carpeta y generalmente incluye:
- index.html
- styles.css

El objetivo es practicar estructura HTML, estilos CSS y diseño básico de páginas web estáticas.

## Proyectos incluidos

- [Colores y sombras](Colores-sombras/)
- [Formulario de registro](Formulario-de-registro/)
- [Formulario](Formulario/)
- [Pianos](Pianos/)
- [Presentación de producto](Presentacion-de-producto/)
- [Prueba de accesibilidad](Prueba-de-accesibilidad/)
- [Rectángulos](Rectangulos/)
- [Web Café](Web-Cafe/)
- [Web Gatos](Web-Gatos/)
- [Web personal (Portfolio)](Web-personal/)


Cada carpeta corresponde a un proyecto independiente.
